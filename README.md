# DriveEase 🚗

DriveEase is a full-stack car rental web application built with Flask, Python, SQLite, HTML, CSS and JavaScript.

## Features

- User registration and login
- Session-based authentication
- Browse cars
- Search and filter cars
- Sort cars by price
- Car details
- Online car booking
- Rental duration calculation
- Automatic total price calculation
- My Bookings
- Booking history
- User profile
- Contact form
- Logout
- SQLite database

## Technologies

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Flask-CORS

## How to Run

```bash
pip install -r requirements.txt
python app.py
